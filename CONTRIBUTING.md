# Contributing

Keep the project lean: one SQLite store, exact retrieval, evidence-first lesson recording, and no copied ACL/AoR data.

Before proposing a change:
1. Run the synthetic test.
2. Add a focused regression test for changed behavior.
3. Check the diff for credentials, identities, absolute paths and operational records.
4. Describe what was tested and what remains unverified.

Do not submit real customer, employee, tenant, or operational data.
